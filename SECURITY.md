# Security

The Kinship plugin and server are small hobby projects made for a role-play free company. The code is public so anyone can read it, and you are welcome to scan it.

## Found something?

If you find a security problem, please tell us so we can fix it.

- **Preferred:** use GitHub's private reporting. On this repo, open the **Security** tab and click **Report a vulnerability**. Only the maintainers will see it.
- **Or email:** Thekinship.ffxiv@gmail.com

Please do not post a security problem in a public issue before it has been fixed. For ordinary bugs, a public issue is fine.

## About this project

This project was made with the help of AI. The maintainer designed the features and directed the work, and the AI wrote the code. A human review and any outside scans are welcome, and we would be glad to hear what you find.

Thank you for helping keep the community safe.
