0.62.0: Bank tab: new Exchange gold for gil section. Submit an exchange ticket and the bankers see it in SM Tools and mail you the gil.
0.61.0: You can now change the name you registered with. Inventory tab, Change my name. Your items, gold and everything else stay with you.
0.60.0: More room. You can now hold 20 item slots (was 10) and have 10 statuses (was 6). New "Plugin Only" tag SMs can give in SM Tools, for members who use the plugin without joining the in-game FC.
0.59.0: Carried items. An item can now give its status just by being in your main inventory, with no need to use it. Several copies give it once, it does not use up your six status slots, and it cannot be cured or removed while you hold the item.
0.58.0: New Jobs tab: a board of quests posted by the SMs. Take a job and do it for the reward. Some jobs are open to everyone, some are first come, first served (and go back on the board if given up).
0.57.0: The plugin is now called Rafter Cat's RP ToolBox (window title, top bar and plugin list). Two new commands, /rrp and /rptoolbox. /kinship still works.
0.56.3: Fixed the "Choose icon" button on the Status tab (the pop-up never opened there).
0.56.2: Quest editor now warns that an NPC or enemy name matches every NPC with that name, in every place.
0.56.1: The About this plugin window now has a section on how the plugin was made (with AI help), what it connects to, and what it sends.
0.56.0: The icon picker now names game icons. Browse game icons has a Group list (armor, weapons, medicine and so on), a search by item name, and hovering any icon shows what it is.
0.55.3: Clearer register screen: it now says the name you enter is your display name for the whole RP system.
0.55.2: New plugin icon.
0.55.1: Two more tags for SMs to use: Kin and Alt.
0.55.0: New "Registered characters and tags" section in SM Tools: see everyone registered, remove them, and give them tags (SM, Banker, Onyx, Vanguard...). Tags show at the bottom of their roster entry and profile card.
0.54.0: Group quests. When you are in a party, a quest step completed by one person moves the quest on for everyone in the party who has the same quest on the same step, with the rewards, and a pop-up tells them.
0.53.4: Anyone can now start a party (no password). Combat encounters still need the SM password.
0.53.3: The Scenes tab is now called Party (same thing: join with a code, popups, group RP). Groundwork for doing quests together.
0.53.2: New Pause button at the top of the Kinship window (also in the top bar right-click menu). While paused the plugin makes no server requests at all. Press it again to turn the plugin back on.
0.53.1: The plugin now pauses its background server checks while you are standing still and not using the mouse for 3 minutes, and picks up again the moment you move. Fewer requests while AFK.
0.53.0: New "World items": leave a copy of an item out in the world (a herb by a tree, a cookie on a table) for anyone to pick up. Choose once, back after a wait, or always. Find them on the new World tab.
0.52.5: Alpha only: sickness diagnosing and curse reading are now also on the Status tab, so testers can use them without the sect pages.
0.52.4: Failed sickness diagnoses and curse readings now give a random message each time instead of the same one.
0.52.3: Fixed a quest area step that could be missed if another request was running when you walked in, and area notices no longer ask the server repeatedly after an error.
0.52.2: Quest area notices and "Walk into an area" steps now react faster. Notice text is loaded as you approach, so it shows the moment you walk in.
0.52.1: The plugin page now shows a fuller description and this changelog.
0.52.0: Quests can now react to where you walk. New "Walk into an area" steps advance the quest when you enter a spot, and area notices pop up when you enter a spot on any step.
