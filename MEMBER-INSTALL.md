# Installing The Kinship plugin (for members)

You need XIVLauncher with Dalamud (the plugin system most players already use).

1. In game, type `/xlsettings` and open the **Experimental** tab.
2. Under **Custom Plugin Repositories**, paste this address into the box:
   `https://raw.githubusercontent.com/The-Kinship/kinship-plugin/main/repo.json`
3. Click the **+** button, then **Save and Close**.
4. Type `/xlplugins`, open **All Plugins**, search for **The Kinship**, and press **Install**.
5. Type `/kinship` to open it.

Updates arrive on their own. Please keep this address to FC members.
